> 对照基准：华泰金工《因子工厂》系列（2024.2 GPT因子工厂 / 2024.9 2.0 / 2025.12 大模型+RL /
> 2026.4 高频特征参数化）、AlphaEval 五维评估（arXiv 2508.13174）、AlphaAgent（KDD'25）、
> Bailey & López de Prado（2014 DSR / 2015 PBO-CSCV / CPCV）。
> 触发：因子库最强因子回测出现总收益 950 亿倍、IC 0.43（真实 A 股日线因子 IC 高分位 ~0.08）——好得不真实。

## 一、发现的问题与修复（按严重程度）

### 🔴 1. B_shift_lag 未来数据泄漏（严重）
- **位置**：`model_core/param_vm.py` 双变量算子 B 的时序错位
- **根因**：`np.roll(b, -lag)` 符号反了——`B_shift_lag>0`（公式文本"滞后N"）实际取**未来 N 天**的 B 值。
  因子在 t 时刻就"看见"未来收益 → 与未来收益相关 0.43（真实水平 ~0.02）→ 回测开卷考试。
- **铁证**（同一公式"open与ret(滞后2)的Corr"、同一数据）：
  | 检验 | 结果 |
  |---|---|
  | 修复前 IC | +0.4321（泄漏） |
  | 修复后 IC | -0.0037（真实） |
  | 新旧因子值相关 | -0.0125（完全不同） |
  | 无泄漏随机公式 \|IC\| 基准 | 均值 0.018 / 最大 0.046 |
- **修复**：`b[t]` 只用 `b[t-k]` 及以前（k=\|lag\|），任何方向都杜绝未来信息。
- **回归锁定**：`tests/test_p8_no_leakage.py`（滞后因子未来相关 ≤ 过去相关）。

### 🔴 2. DSR 公式与 Bailey 2014 原文不符（严重）
- **位置**：`model_core/eval/significance.py::compute_dsr`
- **根因**：实现为 `z = SR̂·√(T−1)/√V − E[maxSR]`，原文为
  `z = (SR̂ − E[maxSR])·√(T−1)/√V`——E[maxSR] 项未乘 √(T−1) 未除 √V，
  **校正被削弱约 √(T−1)/√V ≈ 40 倍**（T=2000）→ DSR 几乎恒为 1.0 → 入库门槛形同虚设。
- **铁证**：非年化 sr=0.10、T=2000、N=383 → 旧实现 DSR=0.933（过 0.90 门槛），原文 DSR=0.00000000。
- **修复**：`z = (sr − emax)·√(T−1)/√V`；同时将 `--dsr-gate` 默认改为 0.0——
  修正公式后 DSR 在 N≥100 时数学上几乎不可能 >0.95（Bailey 的著名结论），改作**报告项**。
- **回归锁定**：`tests/test_p9_institutional.py`（单调性 / 远低于旧实现参考）。

### 🟠 3. 因子后处理全样本 MAD 去极值（前视）
- **位置**：`model_core/param_vm.py::postprocess`
- **根因**：裁剪边界 med/mad 用**全序列**统计量——每个 t 的边界依赖未来数据。
- **修复**：因果滚动窗口 MAD（120 根，t 只用 x[t-119..t]），头部 warm-up 不裁剪。
- **回归锁定**：`test_postprocess_no_future_dependence`（改尾部不影响前面所有 z 值）。

### 🟠 4. 评估无样本外（OOS）三段划分（机构核心）
- **根因**：入库 IC/DSR/五维全部在**全窗口**（含挖掘所用数据）上计算 → 选样偏差直接进认证。
- **修复**（`scripts/mine_full_market.py`）：
  - 挖掘全窗口选优 → 认证只用**最后 25% OOS 段**（`--oos-frac`）
  - OOS 门槛：\|RankIC\| ≥ 0.02 且 不重叠分块 RankIC 的 t ≥ 1.5 且 与训练段方向一致 且 五维 ≥ 0.45
  - **OOS 段 ≥ 250 根（约 1 年）才认证**——短样本上"好得不真实"的偶然强相关（如 Last 类
    退化公式 OOS RankIC -0.55）被拒绝（`oos_insufficient`）
  - 滚动 IC 的 t 检验改**不重叠 20 根分块**（滚动窗口重叠会使 t 值虚高，有效样本膨胀）
  - 负 IC 反向因子记录 `direction=-1`（机构翻转口径），回测按方向翻转仓位

### 🟡 5. 回测成交时点前视
- **根因**：`pos[t]` 在 t 收盘产生信号并以 t 收盘价成交（现实不可行）。
- **修复**（`scripts/factor_backtest.py`）：信号滞后一天执行（`pnl[t] = pos[t-1]·ret[t]`），
  换手成本按执行仓位差分。

### 🟡 6. 拥挤度阈值过松
- 因子库去冗余阈值 0.95 → **0.85**（`--crowd-corr`），拦截"high的Last 60/120 期"式近重复公式。

### 🟡 7. Skew/Kurt 掩码广播错误
- `_op_skew`/`_op_kurt` 掩码分支 `(n,)/(n,1)` 广播成 `(n,n)` 矩阵 → 该类公式执行崩溃被静默淘汰
  （这也是候选池被"退化公式"占据的诱因之一）。已修复 + 500 随机染色体回归锁定。

## 二、对照机构标准的现状

| 环节 | 机构标准 | 本项目现状 |
|------|----------|------------|
| 数据因果性 | 无未来信息（复权/去极值/标准化全部因果） | ✅ 已修（lag/MAD/zscore 因果） |
| 复权口径 | 后复权计算因子（前复权历史价被未来除权改写） | ⚠️ 使用前复权（腾讯 qfq）；收益率/比例类指标不受影响，水平类指标轻微；建议后续切 hfq |
| 因子评估 | IC + RankIC + ICIR + 分组收益 + 换手 + 衰减 | ✅ 五维（PPS/稳定性/鲁棒性/金融逻辑/多样性）+ IC/RankIC/ICIR |
| 样本外 | 训练/验证/测试三段，OOS 显著性检验 | ✅ OOS 25% + 不重叠分块 t 检验 + 方向一致性 |
| 过拟合控制 | DSR / PBO(CSCV) / CPCV | ✅ 公式已修正；PBO/CPCV 实现与 Bailey 2015 / López de Prado 一致 |
| 因子库去冗余 | 相关性去冗余（0.7-0.9） | ✅ 0.85 |
| 成交时点 | t 信号 → t+1 执行 + 成本 | ✅ 已修（滞后一天 + 单边成本） |
| 反向因子 | 负 IC 因子方向翻转 | ✅ direction 字段 + 回测翻转 |

## 三、已知限制与后续建议

1. **单标的时序挖掘的统计功效限制**：每只股票独立挖时序因子，OOS 500 根时真实因子
   RankIC 0.05-0.15 已属强信号；shuffle 对照检验已加入审计方法（真实信号须超出随机基准 95 分位）。
   机构横截面认证（全市场 RankIC + 行业/市值中性化）需要跨标的组合层支持——建议后续在
   FactorStore 之上加横截面面板评估。
2. **前复权 → 后复权**：腾讯 hfq 可用但存在个别除权日 20% 跳变瑕疵，切换前需做跳变清洗。
3. **涨跌停/停牌可交易性修正**：涨停日信号无法成交，机构会剔除或修正——建议后续在回测层加入。
4. **n_trials 上报**：GP 用 pop×gen（实际评估数）——Bailey 建议用"有效独立试验数"
   （遗传共享信息折扣），当前保守（校正更严格），可通过 `trials_indep` 参数调节。
