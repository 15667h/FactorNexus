## 一、现状基线（事实）

### 1.1 已建成（本会话全程构建，151 项测试通过）

| 层 | 内容 | 状态 |
|---|---|---|
| 数据层 | 三源兜底（腾讯 hfq/新浪/通达信）+ D3 健康检查 + 复权冲突检测 | ✅ 机构级 |
| 挖掘层 | GP(NSGA-III) + RL(REINFORCE) + LLM(多智能体) 三引擎矿池联动 + 双 DSL | ✅ 超出个人级 |
| 认证层 | 训练/OOS 分离 + 横截面 RankIC + 中心化块自助 + 五维门槛 + DSR/PBO/CPCV | ✅ 机构级 |
| 策略工厂 | walk-forward(gap) + LGBM/MLP/S4 + 集成(rank_avg/bagging/stacking) + 评估 | ✅ 已跑通 |
| 组合层 | 中性化/正交化/合成/回测(t+1,成本,涨跌停)/Brinson 归因 | ✅ 机构级 |
| 风险预算 | markowitz/risk_parity/black_litterman 面板优化（滚动协方差防前视） | ✅ 已接入 |
| 高频 | 分钟级管线 + 14 日内特征 + OOS 认证入库 | ⚠️ 架子搭好未实战 |
| 执行层 | — | ❌ **未建** |

### 1.2 最新实测（2026-08-28，420 只股票 / 1695 因子 / 58.8 万样本）

```
lgbm       RankIC=+0.0122  IC_IR=+1.2295  单调性=+0.26  多空=+0.0059  分段一致=True
组合层:    多空 Top5 每日调仓 → 总收益 -99.1%（换手 3.83/日 × 成本 → 损耗 470%）
```

**关键判读**：
- 信号本身合格（RankIC 正、IC_IR 1.23 远超 0.8 目标、十分组单调为正）
- 组合亏损 100% 是**交易频率问题**（每日调仓 vs 5 日预测周期），不是选股逻辑问题——
  上一轮已诊断，`--rebalance 5 --n-top 20` 即可修正（此为 P2 第一步）
- 420 只池 RankIC 0.0122 ≈ 139 只池的 0.0132 → **股票池扩大 3 倍信号未衰减**，
  全市场铺满后进入 Qlib 基准区间（LGBM CSI300 官方 0.0469）可期

## 二、差距诊断（课象 × 行业 × 系统三源交叉验证）

### 2.1 执行链路鸿沟（课象"玄武末传"；社区直问"赚钱了吗？并没有"）

| 差距 | 机构 | 我们 |
|---|---|---|
| 模拟盘/实盘 | 专用执行系统 + 券商专线 | **无**（停在回测） |
| 延迟 | 微秒级（托管机房） | 网络下单数百毫秒 |
| 算法执行 | 拆单/冲击成本最小化 | 无（一次下单） |
| 订单状态跟踪 | 全链路审计 | 无 |

**这是"回测 ≠ 实盘"的最后一公里**。Qlib 有 Order Executor 组件，我们的架构图里
这一格还是空的——一切"策略有效"的结论未经真实市场验证。

### 2.2 验证严谨性缺口（社区高手 liulaoqiong 四条拷问）

1. **有 1 分钟级带交易时间戳的防作弊审计吗**——回测中未来函数/时间戳错位的最后防线
2. **能跨周期跨品种吗**——策略是否只在某周期/某品种池上成立（过拟合维度）
3. **去掉 Top5/10 最大赢家后剩余 EV 是否为正**——收益是否依赖少数极端样本
4. **随机入场 EV 是否为正、最坏入场情况**——策略是否只是"市场本身在涨"

这四条我们**一条都还没做过**。它们比任何新模型都重要——先证明已有策略是"真 alpha"
而非"数据巧合"。

### 2.3 策略深度（课象"官鬼旺而克身"；行业"DNN 替代多因子"）

- 主力模型 LGBM（Qlib 基线水平）；机构已上 DNN/LLM 自主研究（微软 RD-Agent 让 AI
  当研究员自主迭代因子库）——我们的 LLM 引擎还在"辅助生成假设"阶段
- 高频因子（P15）搭好未实战；华泰金工 2026.4《高频特征参数化》实证：**分钟级信号
  可使 1000 增强年化超额提升约 2.9 个百分点**——这是我们最容易兑现的增量
- 组合配置仍是"多空 Top5 每日调仓"这种入门配置（应修正为 rebalance=horizon +
  Top20 + 风险预算优化器）

### 2.4 风险预算静态化（课象"丑空亡"——最准的一刀）

我们的 markowitz/RP/BL 是**静态配置**：协方差窗口固定、无市场状态感知。机构的
风险预算按市场状态（波动 regime/流动性）动态调整仓位与策略权重。课象"风险预算
是个花架子"对应现实：**优化器有了，动态化没有**。

### 2.5 资源与团队（课象"比肩不现，孤独是常态"；行业数据）

机构：15 亿私募投研+IT 团队 20+ 人、年运维千万级、万卡算力（幻方萤火二号）、
tick/L2 数据。我们：单人 + 单卡 4060 + 免费数据源。**这一项无法通过代码补齐，
只能通过"聚焦"（P2 建议 1-2 赛道）与"外部视角"（走出闭门造车）策略性缓解。**

## 四、P0 验证严谨性加固（最先做，零成本）

> 对应社区四条拷问。目标：**给"策略有效"这四个字上证据链**。

### 4.1 防作弊审计（审计回测本身）

- **实现**：`scripts/audit_backtest.py`
  - 逐笔信号时间戳 vs 成交时间戳校验（t 收盘信号 → t+1 成交，已有逻辑再加硬断言）
  - 因子值"最后一行改写测试"：改尾部 100 根数据，历史预测值必须逐位不变
    （P8 测试已有滞后因果锁定，此处升级为全链路回测审计）
  - 随机打乱收益面板 → 策略净值必须归零（±统计噪声），作为"无未来函数"的
    最终证明
- **验收**：审计报告输出 3 张证据表（时间戳/因果/随机对照），全部通过

### 4.2 随机入场与极端样本检验

- **实现**：`scripts/robustness_audit.py`
  - 随机入场 EV：1 万次随机持仓（同仓位/同期）的收益分布 → 策略 EV 须超 95 分位
  - 去顶检验：去掉 Top5/Top10 最大单日赢家后重算净值 → EV 须仍为正
  - 最坏入场：从历史最差 10 个交易日入场回测 → 记录最大回撤场景
- **验收**：四项指标输出到 `store/meta/robustness_audit.json`，作为因子/策略入库
  的第四道门（现有：五维 + 块自助 + 方向一致 + 拥挤度）

### 4.3 跨周期/跨品种迁移测试

- **实现**：策略工厂信号在 3 个不同周期（1d/1w/60m）与 3 个不同板块池上重估
  RankIC；衰减 <30% 视为"结构有效"，衰减 >50% 视为"该池过拟合"
- **验收**：迁移矩阵表（周期 × 池 × RankIC），写入评估报告

### 4.4 全市场成绩单（前提性工作）

- 挖矿铺满全市场（当前 420/5000）后重跑 `mine_signal.py`——RankIC 进入 Qlib
  区间（0.03-0.05）即证明"管线正确，只差数据量"；若停滞则说明因子同质化，
  触发 P2 的高频/基本面扩展

### 4.5 P0 执行结果（2026-08-28 真实数据，420 只 × 4227 日）✅ 完成

| 审计 | 结果 | 证据 |
|---|---|---|
| ① 成交时点（t+1） | ✅ 通过 | 脉冲验证：PnL[t] ≡ pulse×Σw[t-1] |
| ② 因子因果 | ✅ 通过 | 篡改尾部 100 根 → 前 5517 根因子最大改写 0.00e+00 |
| ③ 随机收益对照 | ⚠️ 未显著 | 原策略 -19.94% vs shuffle -23.06%±27.49%（32% 分位） |
| ④ 随机入场 EV（2000 次） | ⚠️ 未显著 | 策略 -22.51% vs 随机中位 -15.88%（p95=+71%） |
| ⑤ 去顶检验 | ❌ 依赖赢家 | 去掉 Top5/Top10 赢家后 -34.94%/-44.23%（更差） |
| ⑥ 迁移测试 | ⚠️ 脆弱 | 随机子池 RankIC 波动 -200%~+62%，仅 1/4 子池衰减 <30% |
| ⑦ P2 配置复验（持有5日/Top20） | ⚠️ 仍不显著 | 原策略 -13.46% vs shuffle -11.93%±17.32%（44% 分位） |

**P0 核心结论（最重要的发现）**：
1. **回测引擎与因子管线无作弊**（①②通过）——系统基础设施可信；
2. **当前合成得分信号未通过随机对照**——即使按 P2 修复配置（持有 5 日/Top20），
   多空组合收益与"随机打乱收益后的同权重组合"无统计差异（44% 分位）；
3. **随机多空组合本身负漂移 -15.88%（A 股多空波动税 + 做空端负 Beta）**——
   策略 -13.46% 仅略好于随机中位，远未达显著（p95=+71%）；
4. **RankIC +0.012 与组合负收益不矛盾**：RankIC 正但太小，日期望超额不足以
   覆盖成本与噪声；
5. **行动指向**（与课象一致）：下一步焦点不是基建、不是组合配置微调，而是
   **提升信号 RankIC（扩池、高频、基本面、模型升级）**。

**P0 验收判定**：✅ 完成（审计工具就绪、回归锁定、结论如实记录）——
审计③④⑤⑥ 的"未通过"正是 P0 要的答案：**"策略有效"目前不被证据支持，
需要 P2 信号升级 + 全市场数据验证后重新判定。**

## 五、P1 交易闭环：执行层（最大硬伤）

> 课象："末传玄武，你可能会被自己的技术自信迷惑"——不上模拟盘，一切回测都是
> 自证。目标：**让系统产生第一笔模拟成交，并开始积累实盘偏差数据。**

### 5.1 QMT 模拟盘接入（推荐路径）

- **背景**：QMT（迅投）提供免费模拟盘 + Python API（xtquant），10 万门槛开通
  实盘权限；模拟盘免费且 API 成熟，是个人接入 A 股执行的最低成本路径
- **实现**：`execution/qmt_broker.py`（新建执行层模块）
  - `QMTBroker.connect()/submit_order()/query_positions()/query_trades()`
  - 组合层权重面板 → 每日订单（按 P2 的 rebalance 周期）
  - 成交回报回写 → 与回测预期净值对比（滑点/成交率/延迟偏差跟踪）
- **验收**：模拟盘连续运行 ≥30 个交易日，生成 `execution/sim_track.csv`
  （每日预期 vs 实际持仓/净值，偏差率 <5% 视为执行层合格）

### 5.2 执行成本模型校准

- 用模拟盘真实成交数据校准 `impact_cost.py` 的 Almgren-Chriss 参数（k 系数），
  替换经验默认值——让回测成本贴近真实
- **验收**：回测总成本与模拟盘实际成本差异 <20%

### 5.3 可选的下一步（不阻塞）

- 实盘接入（QMT 10 万门槛 / 券商两融通道）——P1 完成且 P0 通过后再评估

## 六、P2 策略深度（主要收益来源）

> 课象："你会开始意识到策略灵魂的重要性，重心从工厂转向策略研究室。"
> 目标：**把已有 alpha 从"有"变成"大且稳"。**

### 6.1 立即修复：组合配置工程化（半天，立竿见影）

现状：多空 Top5 每日调仓 → 换手 3.83/日 → 成本吞噬 470%。
修复（已诊断，直接落地为默认配置）：

```bash
python scripts/mine_signal.py --rebalance 5 --n-top 20 --optimizer risk_parity
```

- 持有期 = 预测周期（5 日）→ 换手 3.8 → ~0.8
- Top20（420 只池，约 5% 占比）→ 分散单票噪声
- 风险预算优化器 → 换手进一步降至 ~0.05/日
- **验收**：组合收益转正（或接近零轴），成本损耗 <50%

### 6.2 高频因子实战（P15 从架子到产出）

- 华泰实证：分钟级特征参数化 → 1000 增强年化超额 +2.9pct
- 我们已有：通达信 1h/30m/15m/5m 全历史管线 + 14 个日内特征 + OOS 认证入库
- **缺口**：① 特征只有 14 个（华泰框架是分钟级可解释因子参数化挖掘——可用
  我们的三引擎直接挖分钟特征，把 GP/RL/LLM 接到分钟数据上）；② 高频因子与
  日线因子的合成/正交化未做（高频信号衰减快，需与低频互补）
- **验收**：高频因子入库 ≥50 个、与日线因子合成后组合 RankIC 提升 ≥20%

### 6.3 模型升级（策略工厂 M3-M5 上生产）

- MLP/S4 全量 walk-forward 对比（此前只冒烟过）→ 若超 LGBM 则进集成
- stacking 两层上生产（第一层 LGBM+MLP，meta=Ridge）
- 特征工程：基本面因子（P18 已有 7 个）补强——课象建议的"基本面量化"方向
- **验收**：生产信号 IC_IR ≥ 1.0 且分段一致保持 True

### 6.4 聚焦 1-2 赛道（课象最明确指令）

- 全市场因子同质化（420 只池 RankIC 未随规模上升，佐证"广撒网边际递减"）
- **行动**：选定 1-2 个行业（如消费/科技）或 1 个周期（如周频），用全量因子库
  在其中做深度策略——华泰/机构实证：行业聚焦比全市场平庸策略更易出 alpha

## 七、P3 动态风险预算（课象"丑空亡"修复）

> 课象："风险预算模块只是静态配置，而非基于 AI 对市场微观结构实时感知的
> 动态调整。"目标：**从"静态优化器"升级为"状态感知的风险引擎"。**

### 7.1 市场状态识别（Regime Detection）

- **实现**：`model_core/portfolio/regime.py`
  - 波动率 regime（GARCH(1,1) 或滚动波动分位：低/中/高波三态）
  - 趋势 regime（指数均线斜率 + 广度指标：涨/跌/震荡）
  - 流动性 regime（成交额分位）
- **验收**：regime 序列与市场极端事件（2024-02 微盘、2018 熊市）可对齐

### 7.2 状态驱动的动态配置

- **实现**：`optimize_portfolio_panel` 增加 `regime_aware=True`：
  - 高波态：降杠杆（Σ|w| 2→1）、加大协方差收缩（Ledoit-Wolf 权重 ↑）、
    提高 risk_parity 占比
  - 低波态：恢复正常杠杆，markowitz 占比 ↑
  - 涨势态：多空偏多（多头权重上浮）；跌势态：偏空或降仓
- **验收**：regime-aware 组合 vs 静态组合：最大回撤下降 ≥20%、波动下降 ≥15%、
  Sharpe 不降

### 7.3 压力测试剧本

- 2024-02 微盘股流动性危机、2018 全年熊市、2020-02 疫情跳空——三个剧本
  回放组合净值
- **验收**：三个剧本下回撤均 < 静态组合的 80%（动态化价值证明）

## 八、P4 LLM 自主研究闭环（方向布局）

> 行业动向：微软 Qlib 已发布 RD-Agent（LLM 自主研究员：自己读因子库 → 自己
> 提假设 → 自己回测 → 自己入库，闭环迭代）；东吴/广发/国联 2026 密集发布
> LLM 因子挖掘研报。我们的 LLM 引擎（DeepSeek 批级假设注入 GP）已踩对方向，
> 差"自主闭环"。

### 8.1 从"批级注入"到"自主迭代"

- **实现**（改造 `_llm_batch_discovery` → `LLMResearchLoop`）：
  1. LLM 读取因子库健康报告（`factor_monitor.json`：哪些因子衰减/翻转）
  2. 自主提出"修复/替代假设"（而非固定模板假设）
  3. 假设 → 参数化公式 → 快速预筛（简化认证）→ 通过者入候选池
  4. 结果反馈给 LLM（哪些假设被拒、为什么）→ 下一轮更准
- **验收**：LLM 提出的假设通过率从当前基线提升 ≥50%（形成学习曲线）

### 8.2 因子库自洁机制

- 入库因子的 IC 衰减 → 自动降权/淘汰（与 P17 监控联动）
- 拥挤度去重从"入库时"升级为"持续监测"（相关性漂移检测）
- **验收**：因子库半衰期（IC 衰减至一半的时间）中位数提升 ≥20%

## 十一、理性边界提示

1. **本方案基于课象推演 + 公开信息 + 系统实测**——课象仅作趋势参考与自我审视
   的镜子，方案的每一项验收标准都是可量化的代码事实，不依赖玄学
2. **机构差距的硬约束**（算力/团队/tick 数据/执行通道）无法用代码填平——
   方案选择"聚焦 + 验证 + 动态化"路线，避开正面消耗战
3. **回测转正的收益 ≠ 实盘收益**：P0-P1 是这道坎的唯一通路，跳过它直接追
   策略收益是最大的风险
4. **术数边界**：课象吉凶由人事进退决定——方案执行与否、执行深度，最终由
   你对市场的认知与投入决定
