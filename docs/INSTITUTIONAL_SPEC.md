## 六、已确认的架构性限制（诚实披露）

1. **单标的时序挖掘 vs 机构横截面**：机构认证是"全市场截面 RankIC + 行业/市值中性化"；
   本系统每只股票独立挖时序因子（华泰高频参数化同构），统计功效天然低于横截面——
   表现为"单只股票 OOS RankIC 需 ≥0.02 且块自助显著"（比截面门槛宽松是**正确**的，
   因为时序单标的样本功效低；但也不要被 0.3+ 的"超强 OOS"迷惑——短样本+选优残留）。
   组合层（P14）的截面中性化/正交化/合成正是为弥补此架构短板：合成因子再入组合，
   全市场横截面选股。
2. **前复权数据**：收益率类指标与后复权一致；水平类指标有轻微未来依赖（文档披露）。
3. **涨跌停近似**：用价格变动幅度近似（无交易所涨跌停标记数据）。
4. **冲击成本**：固定费率 + 固定滑点模型，无市场深度冲击项。
5. **市值代理**：无流通股本数据，市值/换手用成交额代理（文档披露；有股本数据源可替换）。
6. **高频因子**：通达信分钟线全历史（1h 覆盖约 2 年）；腾讯/新浪分钟线数据量有限（备选）；
   高频特征五维从简（占位 0.5，文档披露），认证走 OOS 显著性口径。
