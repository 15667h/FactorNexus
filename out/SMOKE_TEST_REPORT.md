## 已知小样本限制（非 bug）

| 现象 | 原因 |
|---|---|
| 策略工厂 RankIC=0、组合层截面 RankIC=0 | 横截面 RankIC 需 ≥10 只股票，7 只不足 |
| 中性化 degraded=True | 横截面中性化需 ≥10 只，7 只不足（降级为仅风格中性化） |
| 审计③ 随机对照未显著 | 合成数据 + 样本少，统计功效低 |
| 挖矿机横截面认证降级单标的 | 股票池 <30 → 走单标的认证路径（设计行为） |

## 未覆盖环节（需外部资源，未测）
